# Selangor Economy Compass

build prototype of Input Output (macroeconomics) of State Selangor Dashboard apps based on excel file attached. the output generate GDP, import, productivity and work. In excel files, tab Main are the dashboard based on tab backend IO. Tab 119 are industry based on the standard, tab MSIC code (Malaysian standard of industrial classification), tab simulation are suppose for user to input in order to generate the dashboard while S link, Input calc and BMBI needing help to figure
